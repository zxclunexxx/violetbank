# Violet Bank — Android demo

Полностью офлайн-демонстрация банковского приложения в фиолетовом стиле.

Текущая версия: **1.1 Animated**.

## Возможности

- вход по любым четырём цифрам;
- главный экран, баланс и виртуальная карта;
- демо-переводы и пополнение;
- оплата популярных услуг;
- история операций;
- экран карты с показом реквизитов и заморозкой;
- профиль и выход;
- сохранение демо-баланса между запусками.

## Анимации версии 1.1

- плавные переходы между всеми разделами;
- анимированный вход и фон с плавающими элементами;
- счётчик изменения баланса;
- световой блик на виртуальной карте;
- эффект нажатия и лёгкая вибрация элементов;
- парящая карта на экране реквизитов;
- собственное окно успешной операции с галочкой, свечением и конфетти.

Приложение не запрашивает доступ к интернету и не работает с настоящими деньгами.

## Сборка

Проект собирается стандартными Android SDK Build Tools без сторонних библиотек.
Минимальная версия Android — 8.0 (API 26).
